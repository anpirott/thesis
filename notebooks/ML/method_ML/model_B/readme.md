The [default_models](default_models) contains the experiments on the machine learning models with their default parameters.

The [fine_tuned_models](fine_tuned_models) contains the fine-tuning of the chosen default models.

The [final_models](final_models) contains the fine evaluation on the IVS and training on the whole dataset of the fine-tuned models

Inside each folder, the experiments/fine-tunings are dicided by dataset (MIST and PARSEC).
