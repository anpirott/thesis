The [MIST_v1.2_vvcrit0.0_basic_isos](MIST_v1.2_vvcrit0.0_basic_isos) folder contains the dataset we got from the MIST [website](https://mist.science/model_grids.html). 
We used the version 1.2 of the Theoretical Isochrones with v/vcrit=0.0.

The [PARSEC](PARSEC) folder contains the dataset we got from the PARSEC [website](https://stev.oapd.inaf.it/cgi-bin/cmd). 
We generated new isochrones on the online interface using PARSEC version 2.0 with most of the default parameters except for the ages which we changed to be in log from 5.0 to 10.3 with a step of 0.05 and the metallicities where we used \[M/H\] from −2.75 to 0.5.
